# HM909 (Educational UI & Audio Project)

⚠️ **DISCLAIMER & WARNING**
This repository is an educational programming project created to demonstrate how software interacts with system audio APIs and screen overlays. It is a joke/prank program. 

### What This App Does:
When executed, this script will:
* **Modify UI Focus:** Temporarily overlay the screen and take over window focus.
* **Audio Playback:** Play repeated system sounds/audio loops.
* **File Generation:** Create dummy files within its execution directory.

### What This App DOES NOT Do:
* It **does not** steal passwords, data, or personal information.
* It **does not** log keystrokes or spy on the user.
* It **does not** damage or delete operating system files.

## How to Run It
This project is shared strictly as raw source code. To run it, you must manually install the required libraries and execute the script yourself.
